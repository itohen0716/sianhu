# 絲庵 文化譜

`index.html` は写譜ページ、`annotations.html` は書き込みページです。
入力中の譜面は「▶ 演奏」から `player/` の独立プレーヤーで再生できます。

## v99

- 各段1行の歌詞入力に対応
- 「歌詞なし／歌詞あり」を切替可能
- 歌詞ありは段間隔と印刷ページ分割を自動調整
- 歌詞と表示モードを保存JSONへ保持

## v100

- 1段目の指番号位置を補正
- 1～5段は固定間隔、6段以上は均等配置で印刷
- 歌詞の空白と入力時の横位置を保持し、1行で印刷
- 演奏プレーヤーを文化譜上の中央モーダルへ変更

## v101

- 入力画面の全音符位置を印刷時に実測して同期
- 歌詞の入力欄幅から印刷倍率を自動計算
- プレーヤーを左上へ小型配置

## v102

- 段末の終止符・くり返しB・2本線を譜面内へ揃えて表示
- 左右キーで選択中の譜面部品・奏法・範囲選択を移動
- Enter二回で連音・同時音の塊を終了
- キーボード入力ヘルプへ終了操作を追記

## v103

- 書き込みレイヤーの印刷時Y座標を三本の譜線高へ統一
- 横位置・横幅の変換は維持し、枠・矢印・自由線・コメントの縦伸長を補正

## v104

- 書き込み部品ごとに基準段を固定し、自由線・枠・矢印の形状崩れを防止
- 書き込み全体の左上ずれを右下へ補正
- 枠と自由線の縦寸法、矢印とコメントの大きさ・間隔を再調整
- 未選択時の左右キーを「現在の入力位置」移動へ対応

## v105

- 段終わりの「2本線」「終止符」「くり返しB」を譜面右端基準で再配置
- 入力画面と印刷画面で、段末線の右端と三本の糸の終端を統一
- 書き込みレイヤーの印刷時だけ加わっていた右方向補正を廃止
- v104で調整した縦方向の倍率、文字サイズ、矢印の間隔は維持

## v106

- 入力画面・書き込み画面の段始め記号を、譜面左端専用の座標で描画
- 入力画面・書き込み画面・印刷プレビューの段終わり外側線を、譜面右端へ一致
- 書き込みレイヤーの印刷位置補正はv105の状態を維持

## v107

- 入力画面の段終わり記号を右へ3px補正
- 印刷画面の段始めを左へ3px、段終わりを右へ3px補正
- 書き込みレイヤーと譜面本体の座標変換は変更せず維持

## v108

- コメント文字サイズに「極小」を追加
- コメント入力・再編集を複数行対応に変更
- 文字サイズに応じて改行後の行間と背景枠の高さを自動調整
- 1段目より上へ配置したコメントも印刷プレビューへ反映
- コメントの極小表示・改行・印刷反映を追加。

## v109

- 1段目より上に配置したコメント・枠が印刷SVGの外で切れる問題を修正。
- 既存の枠・矢印・自由線・コメントの譜面に対する相対位置を維持。

## v110

- 数字を移動した後、入力位置を選択しても前回の数字が左右キーで動き続ける問題を修正。
- 譜面セルまたは「現在の入力位置」の左右ボタンを操作した時点で、部品選択を解除。

## v111

- 書き込みページでShiftドラッグによる自由線・矢印・枠・コメントの範囲選択に対応。
- 範囲選択した部品の一括ドラッグ・左右キー移動・Deleteキー削除に対応。

## v112

- 数字・譜線より後ろへ配置する「▰ 背面マーカー」を追加。
- 彩度を抑えた6色、半透明25％、移動・サイズ変更・範囲選択・削除に対応。
- 写譜ページと印刷プレビューでも譜面の背面へ表示。

## v113

- 背面マーカー色が白・青に上書きされ、指定色を確認できない問題を修正。
- マーカー本体は枠線なし・塗りつぶしのみへ統一。
- 選択中の外周線を廃止し、四隅の小さな選択点へ変更。

## v116

- 歌詞の下へ「唄の音程」レイヤーを追加しました。
- 音程数字は文化譜と同じ0～20に対応し、三の糸は印なし、二の糸は「•」、一の糸は「••」で表示します。
- 音価は下線なし＝4分、下線1本＝8分、下線2本＝16分です。
- 唄の音程は三味線の音符とは別データとしてJSONへ保存・読込し、A4印刷にも反映します。
- 将来、唄用の別音色・個別音量・同時再生を追加できるデータ構造にしました。今回は再生機能を含みません。

## v114

- 背面マーカーを実物の蛍光ペンに近い6色・不透明度40％へ変更。
- v113以前に作成したマーカーも新しい色と濃さへ自動変換。
- 数字・開放弦の白背景を透明化し、生成り色の細い文字縁取りを追加。
- 入力画面・写譜ページ・印刷プレビューを同じ表示へ統一。
