# v194 矢印・半間基準・休符時間軸・繰り返し小節入力制御版

- 矢印は、ドラッグ開始点を根元、終了点を矢じり側とする開いた片矢印です。矢じりは本体線と同じ線幅を使い、長さの18%を基本に4～10px相当へ制限し、短い矢印では全長の35%以下へ縮小します。
- 選択した矢印には始点・終点の独立ハンドルを表示します。4px以上動かした時点でリサイズを開始し、始点操作時は終点、終点操作時は始点を固定します。全体移動・色・実線／点線・動的余白の対象外という既存仕様は維持します。
- `〔半間〕` は対象小節の三本線の最下線（`2.5 × row-height`）に、6pxの間隔を足して配置します。画面倍率とコメントによる段移動には譜線と一緒に追従します。半間の時間的意味は変更していません。
- ページ切替は、写譜側を「✎ 書き込みへ」、書き込み側を「♪ 写譜へ戻る」としました。既存の遷移・保存処理は変更していません。
- 休符は4分＝4単位、8分＝2単位、16分＝1単位（16分音符単位）として音と同じ時間区間で管理し、表示糸だけを常に二の糸へ正規化します。既存JSONの休符も読み込み時に同じ扱いへ移行します。
- 音と休符は区間重複を禁止し、異なる糸の同時発音だけは同じ開始位置・同じ音価の和音として維持します。削除後は保存済み占有表を残さず、現在の要素から空き時間を再計算します。
- 「同じ1／同じ2」は小節全体を占有します。繰り返し小節への音・休符入力と、音・休符がある小節への繰り返し記号入力を、最終入力処理で相互に禁止します。記号削除後は通常小節へ戻ります。

# v191 最終印刷DOM・A4段間不足再計算版

- 印刷操作は `printForm submit → applyPrintLayout → ShianPrintV2.render → beforeprint → window.print` の1経路であり、旧 `printRoot` は印刷CSSでも非表示のまま使用されていないことを確認しました。
- v190の境界再構築は実行されていましたが、画面側で次要素までに収まるコメントは追加量0となり、A4用に圧縮された印刷段間で改めて不足量を判定していませんでした。コメント文字は段間と同率縮小されないため、印刷だけ譜線へ接近していました。
- 印刷用の基本段高、コメントの前要素からの相対位置、コメント実高さ、下側余白、次要素の印刷用上端から、印刷DOMで不足する境界量を再計算します。`afterScore`・`afterLyrics`・`afterVocal` を共通処理し、段高の変化を含めて最大12回で収束させます。
- 算出した同じ境界量を、実スペーサーの `height`、段の固定高、後続段の `printTop`、コメントのSVG座標へ渡します。ページ分割前の行モデルとページ内SVGが同じ値を参照します。
- `beforeprint` では最終印刷DOMの段・譜面・歌詞・唄・境界スペーサー・コメントの実矩形を監査し、`data-print-audit` と開発者コンソールへ記録します。印刷CSS適用後の実値と計算値を比較できます。
- 書き込み・写譜の境界判定、コメント移動、歌詞横位置、非コメント部品の編集処理は変更していません。

- 歌詞の全行均等化を廃止し、各文字の所属小節番号と小節内X比率を保存・再利用する方式へ復旧しました。画面幅・写譜・印刷で小節に追従し、縦レイアウト計算は歌詞X座標へ干渉しません。

# v186 上端・下端境界表 試験実装版

- v185のリアルタイム再配置を維持したまま、余白先の判定を「先に最寄り段を決める」方式から、表示中の `score`・`lyrics`・`vocal` を上端／下端順に並べた境界表へ変更しました。
