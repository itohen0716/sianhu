# 絲庵 文化譜

`index.html` は写譜ページ、`annotations.html` は書き込みページです。
入力中の譜面は「▶ 演奏」から `player/` の独立プレーヤーで再生できます。

## v121

- 唄レイヤー中に三味線数字を選び、その真下へ唄を紐づけて入力できるようにしました。
- 唄レイヤーでは三味線数字の移動・変更・削除を行わず、基準位置の選択だけに限定しました。
- 唄の音価は下線表示に使用し、紐づけ入力後は次の三味線数字へ進みます。唄欄を直接押した場合は任意位置へ入力できます。
- 保存・再読込・書き込みページ・印刷で、紐づけ位置と4px単位の微調整を保持します。
- 歌詞・唄の表示切替で段間隔が変わっても、書き込み部品が対応する譜面段へ追従するようにしました。
- 印刷時は唄数字を残し、左側の見出し文字だけを印刷しないようにしました。

# v126 唄スラー・一の糸音価線修正版

- 唄の「部品」からスラーを選び、始点・終点の唄記号を順に押して作成できます。
- スラーは両端の唄記号IDに連動し、数字を移動すると幅と位置が追従します。
- 歌詞線と重ならない専用帯を設け、入力・書き込み・印刷へ反映します。
- 一の糸の8分・16分音価線を入力画面内へ2px上げ、譜線に隠れないよう修正しました。

- 唄レイヤーから三味線の休符を選択し、唄の数字・休符・合いの手を紐づけられるようにしました。
- 連動状態には「4分休符」「8分休符」「16分休符」を表示します。
- 唄レイヤーでは小節線の操作領域を無効化し、段右端の数字・休符を優先してタップできます。
- 小節線の編集は従来どおり「譜線・小節線」レイヤーで行えます。

- 唄レイヤーで表示されていた、三味線譜上の青い入力位置枠を非表示にしました。
- 連動線の始点に青い丸を付け、紐づけた三味線列を明確にしました。

- 連動ガイドの始点を、時間オフセット位置ではなく実際に紐づけた三味線列の中央へ修正しました。
- 唄の `0` は、選択した糸の開放弦を示す `pitchType: "open"` として保存します。

# v130 書き込み段位置完全追随修正版

- 歌詞・唄の表示を切り替える直前に、各書き込み部品の実際の所属段と段内位置を再取得します。
- 表示切替後は、新しい段位置へ同じ段内距離を保って移動します。
- 既存譜面に古い段情報が保存されていても、現在の見た目を基準に補正します。
- 入力ページと書き込みページへ同じ追随処理を実装しました。
- 直線を選択した後も、実線・点線を変更できるようにしました。

# v131 表示切替前後差分による書き込み追随修正版

- 表示切替前に各部品の所属段と、その段の上端座標を取得します。
- 表示切替後に同じ段の新しい上端座標を取得し、前後の差分だけ部品を同期移動します。
- 歌詞のみ表示、歌詞・唄とも非表示、再表示のすべてで同じ計算を使います。
- 再配置を遅延処理せず、用紙を描画する同じ処理内で完了させます。

# v132 レイアウト確定後の書き込み追随修正版

- 表示切替後、ブラウザのレイアウトが確定してから新しい段位置を取得します。
- 背面マーカー、コメント、自由線、直線、矢印、枠を所属段の移動差分でまとめて移動します。
- 歌詞・唄欄の部品は、次段との距離ではなく直前の譜線段へ所属させます。
- 表示ボタンを続けて操作した場合は、古い再配置予約を無効化して最新状態だけを適用します。
- 唄の通常数字は `pitchType: "stopped"`、休符と合いの手は `pitchType: "none"` として区別します。

- 同じ三味線の音列に、開始位置の異なる複数の唄記号を紐づけられます。
- 例：4分の「4・○」へ、8分休符（開始位置）と8分の唄「4」（8分後）を保存できます。
- 選択時は連動先の三味線列を青く表示し、編集画面だけに連動ガイドを表示します。
- 連動位置は入力画面・書き込み画面・印刷で共通です。

# v137 書き込み部品の関連先ラジオボタン試作版

- 書き込みパネルへ「三味線譜・歌詞・唄の音程・用紙固定」の関連先を追加しました。
- 初期値は「三味線譜」です。選択中の部品と、次に作る部品の両方へ設定が反映されます。
- 三味線譜に関連付けた部品は、歌詞・唄の音程を非表示にしても残り、関連する段へ追随します。
- 歌詞または唄の音程に関連付けた部品は、対象欄の表示・非表示と連動します。
- 関連先の切替では保存済みの部品サイズを変更せず、画面表示・印刷時だけ位置を計算します。
