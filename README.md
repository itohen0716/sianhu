- 写譜ページの「保存」「読込」、JSON形式、旧保存譜互換、書き込み座標・印刷処理には変更を加えていません。

# v169 旧保存譜レスポンシブ互換修正版

- 旧保存譜の書き込みに残っている `layoutRow` と `layoutOffsetY` を、現在表示中の同じ段の譜面上端から復元してから、現行の小節・譜線基準アンカー（`layoutAnchorVersion: 3`）へ一度だけ内部移行します。
- 旧座標を現在画面へ直接描画する経路を解消し、通常幅・広幅・狭幅を往復しても、保存済みの論理アンカーから毎回再計算します。
- 旧ファイルは読み込んだだけでは上書きせず、ユーザーが保存した場合に現行アンカー形式で保存されます。
- 新規譜の現行アンカー、スリの `anchor` / `endAnchor`、印刷用の部品再構築、半間情報には変更を加えていません。

# v168 印刷奏法ID・対象音一致修正版

- 印刷専用処理だけが同じ対象音の奏法へ配列順の追加Y移動を行い、通常表示と異なる位置や、重なっていた重複部品を別部品のように見せていた問題を修正しました。
- 奏法・指番号は保存された部品ID、対象音の `m/s/p`、上下指定、手動オフセットだけから印刷位置を再構築します。
- 同一IDまたは同一対象・同一内容の重複は印刷DOMへ二重生成せず、対象音が存在しない孤立部品も印刷しません。
- 奏法レイヤーが印刷対象外の場合は、印刷専用DOMでも奏法・指番号を生成しません。
- 印刷DOMへ部品IDと対象音を検査属性として保持し、通常表示との対応を追跡できるようにしました。
