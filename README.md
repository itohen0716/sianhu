# 絲庵 文化譜

`index.html` は写譜ページ、`annotations.html` は書き込みページです。
入力中の譜面は「▶ 演奏」から `player/` の独立プレーヤーで再生できます。

## v99

- 各段1行の歌詞入力に対応
- 「歌詞なし／歌詞あり」を切替可能
- 歌詞ありは段間隔と印刷ページ分割を自動調整
- 歌詞と表示モードを保存JSONへ保持

## v100

- 1段目の指番号位置を補正
- 1～5段は固定間隔、6段以上は均等配置で印刷
- 歌詞の空白と入力時の横位置を保持し、1行で印刷
- 演奏プレーヤーを文化譜上の中央モーダルへ変更

## v101

- 入力画面の全音符位置を印刷時に実測して同期
- 歌詞の入力欄幅から印刷倍率を自動計算
- プレーヤーを左上へ小型配置

## v102

- 段末の終止符・くり返しB・2本線を譜面内へ揃えて表示
- 左右キーで選択中の譜面部品・奏法・範囲選択を移動
- Enter二回で連音・同時音の塊を終了
- キーボード入力ヘルプへ終了操作を追記

## v103

- 書き込みレイヤーの印刷時Y座標を三本の譜線高へ統一
- 横位置・横幅の変換は維持し、枠・矢印・自由線・コメントの縦伸長を補正

## v104

- 書き込み部品ごとに基準段を固定し、自由線・枠・矢印の形状崩れを防止
- 書き込み全体の左上ずれを右下へ補正
- 枠と自由線の縦寸法、矢印とコメントの大きさ・間隔を再調整
- 未選択時の左右キーを「現在の入力位置」移動へ対応

## v105

- 段終わりの「2本線」「終止符」「くり返しB」を譜面右端基準で再配置
- 入力画面と印刷画面で、段末線の右端と三本の糸の終端を統一
- 書き込みレイヤーの印刷時だけ加わっていた右方向補正を廃止
- v104で調整した縦方向の倍率、文字サイズ、矢印の間隔は維持

## v106

- 入力画面・書き込み画面の段始め記号を、譜面左端専用の座標で描画
- 入力画面・書き込み画面・印刷プレビューの段終わり外側線を、譜面右端へ一致
- 書き込みレイヤーの印刷位置補正はv105の状態を維持
